# Next.js E-commerce Store

This project is a modern and responsive e-commerce platform built with `Next.js`, `Tailwind CSS`, and a variety of powerful libraries. The store is designed to provide a seamless shopping experience with features like product browsing, user authentication, payment processing, and more.

## Tech Stack

- `Next.js 14.2.5`: The React framework for building fast and user-friendly web applications.
- `React 18`: The core library for building user interfaces.
- `Tailwind CSS 3.4.1`: A utility-first CSS framework for rapid UI development.
- `Prisma 5.16.2`: An ORM for seamless database interaction.
- `Supabase`: A backend as a service providing authentication, database, and storage.
- `Clerk`: Authentication and user management.
- `Stripe`: Integrated for payment processing.
- `Radix UI`: A set of React components for building accessible web applications.

## Key Features

- **User Authentication**: Handled by Clerk, providing secure login and registration.
- **Product Management**: Managed via Prisma and a relational database.
- **Payment Processing**: Secure and easy payments with Stripe integration.
- **Responsive UI**: Designed with Tailwind CSS, ensuring a great user experience across devices.
- **Carousel and UI Enhancements**: Enhanced UX with Radix UI components and Embla Carousel.
